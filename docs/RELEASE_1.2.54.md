# NuPhy Lab 1.2.54

[English](#english) · [简体中文](#简体中文)

## English

- Find Santa Hat, Candy Cane, Christmas Tree, Christmas Stocking, Gift Box, and Christmas Bell in Library → Lighting → Presets.
- Bad Apple is an original 30-frame silent lighting loop. Animation previews show unlit keys in black so white silhouettes stand out.
- Meteor, Amber rain, and Teal sweep have been retired from Presets. Copies you saved to My works are still available.
- A Little Heart now uses #DC1210 and Starlight uses #DC9B1F. Each Library category opens on Presets. Opening a lighting work in the editor also displays it on a compatible USB keyboard. The brush defaults to Current pattern.

For an existing installation, go to Settings → About & updates and check for updates. For a fresh installation, [download the macOS installer for Apple silicon](https://github.com/bohu8264/NuPhyLab-next/releases/latest/download/NuPhyLab-macOS-AppleSilicon.dmg).

## 简体中文

- 在「作品库 → 灯光 → 默认预设」中新增圣诞帽、拐杖糖、圣诞树、圣诞袜、礼物盒和铃铛。
- 新增「Bad Apple」，一段 30 帧的原创无声灯光动画。动画预览中，熄灭的按键显示为黑色，白色剪影更清晰。
- 「流星划过」「琥珀落雨」「青绿扫描」已从默认预设移除。之前保存到「我的作品」的副本仍可使用。
- 「一颗小心意」改用 #DC1210，「星光闪闪」改用 #DC9B1F。作品库各分类默认展示预设。打开灯光作品编辑时，已连接的兼容 USB 键盘同步显示该作品。画笔的颜色应用范围默认为「当前图案」。

已经安装的用户可在「设置 → 关于与更新」检查更新。首次安装可[下载适用于 Apple 芯片的 macOS 安装包](https://github.com/bohu8264/NuPhyLab-next/releases/latest/download/NuPhyLab-macOS-AppleSilicon.dmg)。

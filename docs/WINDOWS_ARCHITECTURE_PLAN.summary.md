# Windows 版本计划

## 目前完成到哪里

**Windows 版还在开发，尚未全部交付。** 已接入灯光创作、迎宾动画、普通按键观察、声音、AI 任务状态和维护代码，重点支持 Air75 V3 内部版本 2.0.0.7 的灯光及原设置恢复。

此前的 Windows 10 真实窗口已通过灯光播放、恢复和播放中关窗专项；启动时弹出命令行的问题已修复。这些结果不代替新增功能的整机验收。

## 本轮补了什么

新增用户点击的“切到正在运行的任务窗口”。配合此前的会话恢复和终端（命令行窗口）切回入口，继续支持由其他方式打开、直接安装在 Windows 的 Codex 任务。

后台和桌面程序分别核对任务进程及独立窗口。多个候选、程序变化、用户切走或系统拒绝时停止，不按标题猜测、不发送按键。这只提供普通跳转，不能用来批准 AI 请求。

新入口均已进入源码，之前的安装包不包含它们。Claude 外部窗口和终端标签页仍需手动切换。本轮没有启动新版或切换真实任务，剩余实现完成后再统一打包和人工验收。

## 怎样方便后续维护

界面和作品格式尽量共用。Windows 的设备、声音、按键和任务启动分别由独立模块处理；Mac 的启动方式保持原有实现。

创建终端前核对任务和目录，切换前核对进程和窗口。一并修正存活判断，并完整保留进程创建时间，避免旧编号造成混淆。窗口查询独立处理，网页不能指定程序、窗口或按键。

本地专项 35 项、桌面程序 21 项、进程查询 2 项及前端构建通过；共享回归通过 1158 项，1 项按平台跳过。源码已同步到 Windows，其代码检查、桌面程序 22 项、进程查询 3 项及专项 35 项通过。自动检查与人工验收分别记录。

## 怎样保护键盘

输出灯光前保存原设置，退出时等待恢复确认。异常重开先检查旧记录，不自动继续播放；换设备、版本或档位后重新核对。

现有 F13 到 F24 映射不自动接管或重置。当前固件保留原有自动休眠，长时间灯效可能被中断；部分原灯效会在写入前拒绝。

## 还剩哪些工作

补齐可靠的改键完成确认、实体 AI 任务键、审批、听写，以及 Claude 外部窗口和终端标签页关联。普通按键观察不能用于批准 AI 请求。

之后统一验收保存重开、声音、异常恢复、安装升级、Windows 11、其他键盘和长期运行。正式签名更新仍需真实证书、密钥与地址。

# NuPhy Lab 1.2.59

[English](#english) · [简体中文](#简体中文)

## English

- The default sidebar now shows Lighting Studio, Key Buddy, AI Assistant and Library, in that order. Add or remove tools in Feature Center. Updates keep your saved sidebar and its order.
- Turn on Key Buddy to see a desktop cat type on a KICK75 and reach for the mouse. Choose one of five built-in cats or create one from your own cat photo using a vision-capable model.

To update, open Settings → About & updates and check for updates. For a fresh installation, [download the macOS installer for Apple silicon](https://github.com/bohu8264/NuPhyLab-next/releases/latest/download/NuPhyLab-macOS-AppleSilicon.dmg).

## 简体中文

- 侧栏默认依次显示灯光创作、键盘搭子、AI 助手和作品库。可在功能中心添加或移除工具，升级会保留已保存的侧栏及其顺序。
- 开启键盘搭子后，桌面小猫会跟着你敲 KICK75、动鼠标。可以挑选五只内置猫中的一只，也可以使用支持图片的模型，根据自家猫的照片生成外观。

已经安装的用户可在「设置 → 关于与更新」检查更新。首次安装可[下载适用于 Apple 芯片的 macOS 安装包](https://github.com/bohu8264/NuPhyLab-next/releases/latest/download/NuPhyLab-macOS-AppleSilicon.dmg)。

# Windows 开发进度

## 现在完成到哪里

**Windows 实现已集成到官方 1.2.54。** 本轮固定了开发工具版本，分别在 Mac 和 Windows 按锁定依赖重新检查，并构建完整 Windows 程序与内部安装包。应用由测试者手动启动，工具未改动原作品目录。

## 提交前检查了什么

两版共用功能有 1,527 项自动检查通过、0 失败；另 4 项只适用于 Windows，由 Windows 检查覆盖。Windows 特有功能、程序后台、界面和安装包也已检查通过。测试者直接运行应用，无须安装开发工具。

原重启测试的准备顺序会偶尔取消自己的动画，现在先准备完成，再开始连接。检查标准和时限保留。网络错误会留下更多记录，但原来的网络错误尚未在本机重现。

本机内存较少，后台检查改为逐项运行，保留所有检查标准；GitHub 仍按原方式并行检查。本轮按“本地通过后再提交推送”执行；推送后的 GitHub 两项检查另行确认，当前结果可从合并申请页面查看。

## 哪些灯光体验已经验证

此前在 Windows 10、有线连接的 Air75 V3 2.0.0.7 上，静态播放、连续呼吸、恢复原灯效和动画中正常退出恢复均通过。你已确认实体呼吸变化。

恢复和退出后，独立读取的灯效、104 个灯位颜色、休眠和完整键位与基线一致，没有待恢复记录。两份原作品一致，设置变化和原备份保留。

## 还需要验证什么

继续按场景验证新包安装、保存重开、声音、真实输入、Windows 11、升级卸载和长期运行。代码构建通过不能代替这些真实使用场景。

Windows 与 Mac 尚未完全一样。音乐演奏、智能框选、键盘口袋、语音和屏幕类工具等还没有完整提供；将改键保存到键盘、通过真实 AI 按键执行、审批和听写仍未开放。Windows 独立签名入口已提供，默认使用 Talkflow 公开配置，无需每次设置环境变量，PIN 仍在签名时输入。真实 UKey 签名和安装验收待完成，自动更新保持关闭。

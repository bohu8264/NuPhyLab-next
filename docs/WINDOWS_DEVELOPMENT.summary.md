# Windows 开发进度

## 现在进展到哪里

**Windows 实现已集成到官方 1.2.54，源码提交为 2b4a1b1。** 本轮已同步到 Windows，构建完整程序和内部安装包，并在真实桌面启动。验收结束后，新版保持正常打开。

## 哪些灯光体验已经验证

在 Windows 10、有线连接的 Air75 V3 2.0.0.7 上，已完成爱心静态播放、循环呼吸、点击恢复原灯效，以及动画播放中正常退出恢复。你已确认实体键盘能看到呼吸变化。

停止和退出后均用独立程序重新读取，原灯效、104 个灯位颜色、休眠和完整键位一致，退出后没有待恢复记录。测试图案没有保存，原有两份作品内容一致；设置变化及原备份保留。

## 构建与自动检查怎样

Windows 完整 release、前端类型构建、桌面程序和约 29 MB 的内部安装包均构建通过。源码与包内运行文件也核对一致。安装包尚未实际安装。

此前 Windows 专项 263 项通过、1 项按平台跳过；审查修复后的相关检查 48 项、宿主 25 项通过。共享回归的 24 个官方原版失败仍保留，没有把灯光实测扩大成整体功能验收。

## 哪些能力还没有开放

Windows 和 Mac 的功能尚未完全一样。两端共享界面和业务，底层分别使用 Tauri 与 Swift；音乐、智能框选、键盘口袋、语音和屏幕类工具等没有在 Windows 完整移植。

真实改键、可信实体 AI 按键、审批和听写继续关闭。Claude 外部窗口与终端标签关联仍未完成。Windows 的固件资格独立维护，已有自定义按键不接管、不重置。

## 下一步验证什么

继续验证保存重开、声音和真实输入，再安排 Windows 11、安装升级卸载及长期运行。正式签名和自动更新仍需真实证书、密钥与发布配置。

当前结果只覆盖这台电脑、这把键盘和当前固件；旧版验收记录继续作为历史保留。

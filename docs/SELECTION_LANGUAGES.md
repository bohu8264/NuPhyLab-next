# 界面与翻译语言 / Interface and translation languages

设置中切换中英文界面后，功能页面、框选提示和回答浮窗会同步切换。内置作品名称也会按界面语言显示；用户自己命名的作品、选区文字、问题和模型回答保留原文。

Changing the interface language in Settings also updates feature pages, selection hints and answer controls. Built-in artwork titles follow the interface language. Custom artwork titles, selected text, questions and model answers keep their original text.

智能框选页的“翻译为”可选择默认目标语言。翻译回答浮窗中也能调整，调整后会重新翻译当前选区。选择会自动保存，退出重开后仍有效，与中英文界面设置相互独立。

Choose a default target under **Translate to** on the Smart Selection page. The same selector is available in a translation answer; changing it translates the current selection again. The choice is saved across restarts independently of the interface language.

支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语、阿拉伯语、印地语、泰语、越南语和印度尼西亚语。模型的翻译能力决定结果质量。升级前没有设置过目标语言时，继续使用简体中文。

Targets include Simplified Chinese, Traditional Chinese, English, Japanese, Korean, French, German, Spanish, Portuguese, Italian, Russian, Arabic, Hindi, Thai, Vietnamese and Indonesian. Translation quality depends on the selected model. Existing installations without a target preference continue to use Simplified Chinese.

提问中明确指定的目标语言优先于默认设置；普通总结或解释不会因为翻译目标语言而自动变成翻译。

An explicit target language in a question takes precedence over this default. A summary or explanation is not converted into a translation simply because a target language is selected.

语言菜单中的 **简体中文** 始终使用这一中文名称，方便识别。界面语言、翻译目标和本机语音识别语言相互独立；本机语音识别使用此 Mac 的首选语言，切换软件界面语言不会更改当前录音的识别语言。

The **简体中文** option keeps its Chinese name in language menus. The interface language, translation target and local speech-recognition language are independent. Local speech recognition uses this Mac's preferred language; switching the app's interface language does not change the language of an active recording.

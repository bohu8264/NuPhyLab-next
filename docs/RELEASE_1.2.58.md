# NuPhy Lab 1.2.58

[English](#english) · [简体中文](#简体中文)

## English

- On first launch, NuPhy Lab uses the first supported language in your Mac’s preferred language list. Choose Follow System, English or Simplified Chinese in Settings → General.
- Chinese language preferences display Simplified Chinese. NuPhy Lab uses English when your preferred language list contains neither English nor Chinese. Existing saved language preferences are kept.

To update, open Settings → About & updates and check for updates. For a fresh installation, [download the macOS installer for Apple silicon](https://github.com/bohu8264/NuPhyLab-next/releases/latest/download/NuPhyLab-macOS-AppleSilicon.dmg).

## 简体中文

- 首次打开时，NuPhy Lab 会按 Mac 的首选语言顺序显示英文或简体中文。可在「设置 → 通用」选择跟随系统，也可固定使用简体中文或英文。
- 首选语言匹配中文时显示简体中文。首选语言列表中没有英文或中文时，NuPhy Lab 使用英文。已有的语言设置会保留。

已经安装的用户可在「设置 → 关于与更新」检查更新。首次安装可[下载适用于 Apple 芯片的 macOS 安装包](https://github.com/bohu8264/NuPhyLab-next/releases/latest/download/NuPhyLab-macOS-AppleSilicon.dmg)。

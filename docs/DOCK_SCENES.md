# Dock Scenes / Dock 场景

[English](#english) · [简体中文](#中文)

## English

Dock Scenes saves different lists of pinned applications on your Mac so you can switch between them. Open **Feature Center**, find **Dock Scenes**, choose **Add**, then open it from the sidebar.

### Get started

1. On first opening, the current pinned apps and their order are saved as **All**. Select a scene card to preview it.
2. **Design** and **Entertainment** start with suggestions from apps installed on your Mac. Choose **Edit scene** to add or remove apps. Drag to reorder them, or use the up and down buttons.
3. Choose **New scene** to create your own list. Name it, add apps, then choose **Apply to Dock** to switch. The Dock may briefly disappear while it refreshes.
4. Select **All** and choose **Apply to Dock** to return to the original saved list of pinned apps.

You can rename or delete custom scenes. **All** retains the original saved layout for restoring the Dock. **Missing** in a preview means an app has moved or is unavailable. Remove or add it again in an editable scene before applying that scene.

### Optional shortcuts

The **Scene shortcuts** switch starts off. Select a scene, choose **Set shortcut**, press and release a key combination in the dialog, then enable **Scene shortcuts**. Each scene can have its own shortcut. A warning appears if macOS or another app already uses the combination. Use the same dialog to change or remove it.

With **Scene shortcuts** off, you can still use **Apply to Dock**. Removing Dock Scenes from the sidebar turns its shortcuts off. Re-add it and enable them when needed. Your scenes and saved bindings are retained.

### If a switch is incomplete

If the page says the last switch was not confirmed, review the current Dock and choose **Restore original Dock**. After changing the Dock elsewhere, choose **Reload** to read its current state before trying again. **All** continues to refer to the original saved layout.

Scenes are stored on this Mac, and shortcuts work while NuPhy Lab is running. You can use Dock Scenes without a NuPhy keyboard connected.

## 中文

Dock 场景把不同的固定应用列表保存在本机，方便在工作安排之间切换。打开 **功能中心**，找到 **Dock 场景** 并点击 **添加**，然后从侧栏打开。

### 开始使用

1. 首次打开会将当前固定应用及顺序保存为 **全部**。选择场景卡片查看预览。
2. **设计** 和 **娱乐** 会从本机已安装的应用中提供初始列表。选择 **编辑场景**，添加或移除应用，拖动调整顺序，也可使用上移、下移按钮。
3. 点击 **新建场景** 创建自己的列表。为场景命名并添加应用后，点击 **应用到 Dock** 切换。Dock 刷新时可能短暂消失。
4. 选择 **全部** 并点击 **应用到 Dock**，可回到首次保存的固定应用布局。

自建场景可以重命名或删除。**全部** 保留首次保存的布局，可用来恢复原 Dock。场景预览中的 **未找到** 表示应用已移动或不可用，请先在可编辑场景中移除或重新添加该应用。

### 可选快捷键

**场景快捷键** 初次使用时关闭。选择场景，点击 **设置快捷键**，在弹出的窗口按下并松开组合键即可保存，再开启 **场景快捷键**。每个场景可设置自己的组合键；系统或其他应用已占用的组合会显示提示。可在同一窗口更换或移除快捷键。

关闭 **场景快捷键** 后，仍可使用 **应用到 Dock** 按钮。将 Dock 场景从侧栏移回功能中心会关闭场景快捷键；再次添加后请按需开启。场景和已保存的组合键会保留。

### 切换未完成时

若页面提示上次切换尚未确认，请先查看当前 Dock，再选择 **恢复原 Dock**。如在其他地方调整了 Dock，可点击 **重新读取** 查看当前状态后重试。**全部** 始终对应首次保存的布局。

场景保存在当前 Mac，可在 NuPhy Lab 运行期间使用快捷键。Dock 场景也可在未连接 NuPhy 键盘时使用。

# Windows 新版与检查进度

## 灯光体验验证了什么

在 Windows 10、有线连接的 Air75 V3 2.0.0.7 上，爱心静态播放、连续呼吸、恢复原灯效和动画中正常退出恢复均通过。你已确认看到呼吸变化。

恢复和退出后，独立读取的灯效、全部灯位颜色、休眠和键位与测试前一致，没有待恢复记录。两份原作品一致，设置变化和原备份保留。

## 这次修好了哪些检查

- Windows 准备程序的解压方式不兼容，现已换成兼容方式。
- Mac 自动检查缺少更新框架，现已在检查前准备。
- 24 项旧测试没有跟上新版功能开关或接口，已修正测试准备；游戏仍默认关闭。

Windows 解压 4 项、相关共享检查 126 项、灯光计时 9 项和 Mac 原生检查 3 项均通过。完整共享回归 1,525 项通过、0 项失败，另 4 项按平台跳过。全部共享测试由 Mac 执行，Windows 继续执行专用检查和安装包构建。

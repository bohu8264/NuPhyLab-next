# Windows 新版与检查进度

## 这次完成了什么

**本轮已完成两台电脑上的提交前检查，并构建新的 Windows 内部安装包。** 程序继续保留官方 1.2.54 的新版功能；本轮只生成并核对文件，应用留给测试者手动启动。

## 怎样减少本地通过、远程失败

此前两边使用的构建工具版本不同，导致本地没有发现远程新增的检查。现在把工具版本固定到项目中，两台电脑和 GitHub 都使用同一组版本。

本轮重新准备运行环境，检查两版共用功能、Windows 特有功能、程序后台和界面，并实际生成安装包。共用功能有 1,527 项自动检查通过、0 失败；另 4 项只适用于 Windows，由 Windows 检查覆盖。

重启测试曾因准备步骤先后不确定而失败，现在先完成设置，再开启自动连接。网络失败会留下更完整的记录。原来的网络错误还没在本机重现，不能认定原因已经查清。

## 什么时候算检查完成

本机内存较少，后台检查改为逐项运行，保留所有检查标准；GitHub 仍按原方式并行检查。本地检查通过后才提交、推送；随后继续确认 GitHub 的两项检查。**本地通过提高确定性，远程通过仍需查看当前结果。**

[查看 GitHub 自动检查](https://github.com/bohu8264/NuPhyLab-next/pull/3/checks)

## 灯光体验和使用边界

此前在 Windows 10、有线 Air75 V3 2.0.0.7 上，静态和呼吸播放、恢复原灯效、动画中正常退出恢复均通过。原作品和设置备份保留。

本轮自动检查没有操作真实键盘。新包的安装升级、保存重开、声音、真实输入、Windows 11 和长期使用继续按场景验收。Windows 目前还没有完整提供音乐演奏、智能框选等功能。将改键保存到键盘、通过真实 AI 按键执行操作，以及正式发布的签名和自动更新，仍未开放。

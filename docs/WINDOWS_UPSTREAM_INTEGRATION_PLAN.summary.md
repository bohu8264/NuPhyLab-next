# Windows 新版灯光实测通过

## 现在完成到哪里

**新版已在 Windows 电脑构建成功，并保持打开。** 源码来自已提交的官方集成分支，保留新版 Mac 功能；Windows 继续使用 Tauri 桌面程序。已有约 29 MB 的内部安装包，本轮直接运行完整程序目录，没有执行安装器。

## 三项测试有什么结果

- **播放通过。** 爱心图案能提交到真实键盘，呼吸动画持续输出，你也确认看到了灯光连续变亮、变暗。
- **恢复原灯效通过。** 点击恢复后，独立程序重新读取键盘，灯效、全部灯位颜色、休眠和键位与测试前一致。
- **退出恢复通过。** 动画仍播放时正常关窗，程序退出后再次独立读取，原设置一致，也没有留下待恢复记录。

测试使用 Windows 10、有线模式和 Air75 V3 的 2.0.0.7 固件。临时图案没有保存，原有两份作品内容一致。设置部分有变化，当前值和原备份都保留，没有用备份覆盖你的设置。

## 怎样继续使用

新版位于 Windows 的独立验收目录，完整启动路径见详细报告。旧版保留。新版主程序已确认使用图形窗口，验收结束后移除了调试参数与临时任务。

实现代码仍为已验收版本；验收记录与功能差异说明单独保存到 Git，没有推送或对外发布。

## Windows 和 Mac 一样了吗

还没有全部一样。两端共用新版界面、灯光业务和作品格式。Windows 已验证核心灯光，但音乐演奏、音乐库、智能框选、键盘口袋、语音和屏幕类工具等仍未移植或开放。真实改键、实体 AI 操作也未开放，声音和按键等能力还需实机验收。

## 还有什么需要验证

Windows 11、安装升级、保存重开、声音、真实输入、其他设备与长期使用仍待验收。真实改键、实体 AI 按键、签名和自动更新的限制保持。

此前共享自动检查仍有 24 个官方原版也能复现的失败，清单保留。统一 release 命令仍是另一个待审核方案。

# NuPhy Lab — 中文指南

[中文 / English 首页](README.md) · [English guide](README.en.md)

NuPhy Lab 是适用于 macOS 的 **NuPhy AIR65 / AIR75 / AIR100 V3、NODE75 / NODE100（LP / HP）及 Kick75（ANSI）** 灯光创作软件。USB 插入后自动识别型号，作品按键盘分别保存。

提供绘图、动画、按键触发、游戏、声音律动、作品库，以及 Codex / Claude Code 任务快捷键和状态灯。

## 下载与安装

**[直接下载最新版 Mac 安装包](https://github.com/bohu8264/NuPhyLab-next/releases/latest/download/NuPhyLab-macOS-AppleSilicon.dmg)**

适用于 **Apple Silicon 和 macOS 13.5 及以上版本**。安装包使用 NuPhy 公司 Developer ID 签名并经过 Apple 公证。

[最新版本与更新说明](https://github.com/bohu8264/NuPhyLab-next/releases/latest) · [历史版本](https://github.com/bohu8264/NuPhyLab-next/releases)

1. 安装前先退出旧版 NuPhy Lab。
2. 打开 DMG，将 **NuPhy Lab** 拖入「应用程序」。如提示则替换旧应用，只保留一个已安装副本。保留本机应用数据，继续使用原有作品、草稿和设置。
3. 用 USB 数据线连接键盘并切到有线模式，按软件提示完成授权和固件检查。

首次使用按提示授予输入监控和辅助功能权限。软件可能自动关闭并重新打开一次，使新权限生效。声音权限在实际启用声音律动时请求。

需要更新键盘固件时，请按 NuPhyIO 提示操作；升级完成后关闭官网页面，再回到 NuPhy Lab。

兼容固件、型号和验证范围请见[键盘兼容性](docs/KEYBOARD_COMPATIBILITY.md)。AIR65 V3 没有实体 F 区，不提供 F1–F12 自动接管。

## 自动感光背光

在 **设置 → 灯光与休眠** 可开启自动感光背光：明亮时关闭或保留微光，较暗时平滑亮起，并可按键盘型号学习手动亮度偏好。默认关闭，需要 Mac 支持环境光读取；仅调节 USB 下由 Lab 播放的兼容逐键背光。读数不可用或合盖时回到手动亮度。[完整说明](docs/AMBIENT_BACKLIGHT.md)

## 模拟声浪

在侧栏“灯光游戏”下方打开 **模拟声浪**。麻将、奶油、木质、轻柔、段落、复古六类各三款，共 18 款，可试听和收藏。总音量、回弹、自然变化，以及空格、回车、退格、左右 Shift、Tab、Caps Lock 的音量均可调节。

首次默认关闭，开启后在其他应用中打字也会播放。声音随应用提供，不需要下载或 API；试听不需要输入监控，打字播放需要这项权限。声浪不记录文字或上传输入。[使用说明与声音来源](docs/TYPING_SOUNDS.md)

## 演奏模式

打开 **实验室 → 演奏模式**，把电脑键盘变成乐器：六种音色、八个鼓垫、16 步鼓机，以及八个可自由替换的片段槽位。作品库提供 18 首原创预设和 36 个片段；先选槽位，再选择素材，可以改编为自己的作品。

录制和修改自动保存在本机，可复制、改名、删除后恢复，也可导出工程和 WAV。音源随应用提供，无需 API 或麦克风权限。演奏按键仅在本窗口前台生效；切换应用会释放按住的音符，最小化或休眠会停止播放。循环和试听可在普通切换应用后继续，按 Esc 或停止按钮结束。[使用说明、声音来源与限制](docs/PERFORMANCE.md)

如果作品在保存期间被删除或恢复，旧页面会暂停保存。请先导出当前工程备份，再用 **窗口 → 恢复演奏页面** 打开已保存的作品。

## AI 助手

在 AI 助手中开启 Codex 模式后，默认命令键如下：

| 按键 | 功能 |
| --- | --- |
| F7 | 切换普通 / 极速模式 |
| F8 | 批准当前请求一次 |
| F9 | 拒绝当前请求 |
| F10 | 新建聊天 |
| F11 | 按住听写，松开结束 |
| F12 | 发送聊天输入框中的内容 |

F8、F9 需要当前存在审批请求；F12 需要聚焦聊天输入框。命令键分配可在 AI 助手中修改。

## 实验室：框选提问

框选提问需要 **macOS 14 及以上版本**，键盘功能仍支持 macOS 13.5。

1. 打开 **设置 → 模型与 API**，选择服务和模型，保存自己的 API Key。可选更多预设模型、在支持的服务中读取账户模型列表，或填写模型 ID 和兼容端点。
2. 在 **实验室 → 框选提问** 开启功能，完成辅助功能、输入监控及屏幕录制授权。软件会核对权限与实际监听状态。
3. 按住快捷键拖动框选，松开后执行默认动作；框选时可滚轮切换翻译、总结、解释和回复。默认快捷键为 **⌥ ⇧ Q**，可以自行修改。
4. 在“翻译为”选择中文、英语、日语、韩语等 16 种目标语言。回答浮窗也能修改目标，选择会自动保存，且不随界面语言改变。

也可将快捷键设为鼠标侧键：点击快捷键按钮，按下并松开所选侧键即可保存。之后按住该侧键移动鼠标框选，松开完成，无需再按左键。

选择“回复”后，框选对方的话，可同时说出语气和要点，例如“谢谢邀请，委婉拒绝”。软件会生成可复制发送的回复正文；没有口述要求时，也会根据对话拟好回复。回复使用对话的语言，或你明确指定的语言。

需要口述问题时开启“按住说话”，再允许麦克风和语音识别；录音在本机转写，不上传。下方“发送图片”开关控制是否允许附带选区图片，所选模型和端点必须支持图片输入。

选区文字、问题，以及启用后按操作需要附带的图片会发送到自己配置的模型服务。API Key 保存在本机钥匙串。新用户默认关闭框选和语音，可以按需开启。

## 更新与兼容

应用内置签名更新，会自动检查新版；也可在应用菜单或 **设置 → 关于与更新** 点击 **检查更新**。安装会保留作品、草稿和设置。旧 1.1.x 用户需要先手动安装一次当前最新版。

灯效需要 USB 连接；AIR75 V3 蓝牙另支持快捷键控制。当前键盘布局为 ANSI。

诊断记录仅保存在本机；更新检查不上传任务内容、作品或键盘输入。

## 源码与开发

[项目源码](https://github.com/bohu8264/NuPhyLab-next/tree/main) · [发行版本](https://github.com/bohu8264/NuPhyLab-next/releases)

需要 macOS、Xcode 命令行工具和 Node.js 22 以上版本。

```sh
npm run setup
npm run build
npm test
npm start
```

运行 `npm start` 前先正常退出已安装的 NuPhy Lab 和其他键盘控制程序。源码服务读取真实本机数据，并可能自动连接键盘；自动回归使用隔离数据。

原生构建会下载固定版本的 Sparkle，并验证 SHA-256。运行 `npm run fetch-node` 获取独立运行时，再使用 `npm run package` 打包。对外发布请遵循[发布流程](docs/RELEASING.md)，包括签名、公证、安装包及应用内更新验证。

## 拖拽转换

在 **实验室 → 拖拽转换** 开启功能，从访达拖起文件，按 Shift（也可先按住再拖），移到菜单选项后松手。默认触发键为 Shift，可在页面自定义为单个修饰键、字母、数字、方向键或其他受支持的按键。转换在本机完成，原件保留，同名副本自动编号；进度、取消和最近 20 次结果都在页面中，不弹出额外结果窗口。无需 API 或模型下载。

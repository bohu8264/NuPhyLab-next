# Software updates / 软件更新

[English](#english) · [简体中文](#中文)

## English

NuPhy Lab checks for software updates automatically. You can also check from the application menu or **Settings → About & updates → Check for Updates**.

- [Download the latest installer](https://github.com/bohu8264/NuPhyLab-next/releases/latest/download/NuPhyLab-macOS-AppleSilicon.dmg)
- [Latest release notes](https://github.com/bohu8264/NuPhyLab-next/releases/latest)
- [English guide](../README.en.md)

Updates retain artwork, drafts and settings. Users on 1.1.x need to install a current version manually first.

- [下载最新版安装包](https://github.com/bohu8264/NuPhyLab-next/releases/latest/download/NuPhyLab-macOS-AppleSilicon.dmg)
- [最新发行说明](https://github.com/bohu8264/NuPhyLab-next/releases/latest)

更新保留作品、草稿和设置。旧 1.1.x 用户需要先手动安装一次新版。
